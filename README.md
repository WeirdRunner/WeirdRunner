#### Projects

I'm training a faster decision model of my own to replace the engines it uses today: a ~300M-parameter encoder that answers ~20 typed questions about a posting in one forward pass (0.15 s per posting on a T4), benchmarked against a commercial decision API.

Its self-test passes 93/93 scenarios with 0 missed or false notes.

- **[Ouroboros](https://github.com/WeirdRunner/Ouroboros)**: fine-tunes Jamba-Reasoning-3B (attention + Mamba + MoE) for latent reasoning, trainable end to end on free Kaggle GPUs.
- **[Skill-Binder](https://github.com/WeirdRunner/Skill-Binder)**: a portable Markdown skill library any LLM agent can follow.
